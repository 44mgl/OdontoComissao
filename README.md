# Odonto Comissão

O **Odonto Comissão** é uma plataforma para organizar e apresentar as informações de uma comissão de turma de Odontologia.

O projeto permite:

- publicar notícias, destaques e informações da turma;
- apresentar os membros da comissão;
- divulgar eventos e o cronograma da turma;
- disponibilizar um catálogo de produtos;
- permitir reservas de produtos, sem pagamento online;
- oferecer uma área exclusiva para membros VIP;
- disponibilizar um painel administrativo para gerenciar conteúdos, produtos, estoque, membros e reservas.

O sistema é composto por uma API desenvolvida em ASP.NET Core e por uma aplicação web front-end responsável pela interface e pela navegação dos usuários.
